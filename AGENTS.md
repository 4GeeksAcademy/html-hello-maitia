# Reglas para el desarrollo del sitio web

Estas reglas deben revisarse antes de trabajar en el proyecto.

## HTML y estilos
- Escribe HTML semántico.
- Mantén el CSS en un archivo propio, separado del HTML.
- Acompaña el contenido con `Textbox` para los estilos donde se necesite.
- Diseña de forma responsiva.
- Sigue un enfoque **mobile first** y adapta la página adecuadamente a otros dispositivos.

## Accesibilidad
- Aplica buenas prácticas de accesibilidad, incluyendo compatibilidad con lectores de pantalla.
- Sigue las pautas WCAG y busca contraste AAA siempre que sea posible.

## SEO y GEO
- Aplica buenas prácticas de SEO y GEO en el HTML.
- Utiliza datos estructurados de Schema.org cuando corresponda.

## Restricciones
- No utilices frameworks.
- No utilices JavaScript.
